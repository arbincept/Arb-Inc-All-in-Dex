I build Arb-Inc All-in-Dex, an open-source interface for exploring DeFi: KyberSwap aggregation on BNB Chain, EVM/Solana bridging through Mayan Finance, and a limit-order interface.

A starting point: select BNB → USDT, connect a wallet to request a quote, and inspect the output, route, fees and slippage before deciding whether to trade. Wallet-based trading and the hosted reward service with its server-side signer are documented separately.

Built with Next.js, React, TypeScript, viem and wagmi. The README includes setup instructions, fee disclosures and provider dependencies. A demo storyboard is available; a live quote recording is still pending.

Try it: https://arbitrage-inc.exchange/swap-all
